La Ruée vers l'Or - partie en réseau (5ème et CAPES)

METTRE LE JEU SUR INTERNET (gratuit, 2 minutes)
1. Aller sur https://app.netlify.com/drop
2. Glisser ce dossier « la-ruee-vers-l-or » dans la page.
3. Netlify donne une adresse (https://....netlify.app) : c'est l'adresse du jeu.
4. Créer un compte Netlify gratuit pour garder le site, et renommer l'adresse si besoin.

EN CLASSE
- Professeur : ouvrir l'adresse sur l'ordinateur du tableau, cliquer « Créer une partie ».
  Choisir le niveau, le nombre de questions et les thèmes. Un code et un QR code s'affichent.
- Élèves : scanner le QR code (ou ouvrir l'adresse, « Rejoindre une partie », taper le code et leur nom).
- Quand tout le monde est là : « Lancer la partie ». Le tableau affiche le classement en direct.
- Si la page du professeur est rechargée, cliquer « Reprendre cette partie » : les téléphones se reconnectent seuls.
- « Jouer sur un seul écran » ouvre l'ancienne version au tableau (sans téléphones).

ATTENTION
- L'ordinateur du professeur et les téléphones doivent avoir internet pendant toute la partie.
- Certains réseaux d'établissement bloquent les connexions directes entre appareils.
  Faire un essai avant le cours ; si ça bloque, essayer avec les téléphones en 4G.
- Ouvert en double-cliquant sur index.html (sans Netlify), seul le mode « un seul écran » fonctionne.
